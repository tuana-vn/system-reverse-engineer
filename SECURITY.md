# Security Policy

This repository contains GitHub Copilot agent definitions, skills, workflow specifications, documentation, and local supporting tools such as Python-based validators.

These files are intended to support evidence-backed reverse engineering and engineering analysis workflows. The repository itself does not grant permission to submit, upload, or process third-party, confidential, proprietary, or customer source code with any AI service.

Before using this project against non-public source code, users are responsible for ensuring that the selected AI service, account, deployment model, data-handling configuration, and organizational policies permit that source code to be processed.

Use of this repository does not override customer, employer, contractual, regulatory, or organizational restrictions governing source-code disclosure or AI-assisted processing.

## Reporting Security Issues

If you discover a security issue in this repository, avoid including confidential or proprietary source code, credentials, tokens, customer data, or other sensitive information in a public issue.

Report the issue through an appropriate private channel available to the repository maintainers.
